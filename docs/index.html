The pain point

Everyone is adding agents. Nobody is asking what they cost.

The hackathon guidebook asks whether the extra reasoning and retrieval steps are worth the extra complexity and token cost. Most submissions will report accuracy and stop there.

63%

Plain RAG fails structurally

"How many cycling events had more than 30 competitors?" needs up to 43 documents. A top-10 retrieval cannot hold that evidence, so aggregation accuracy is 10%.

97%

GraphRAG stops at ambiguity

When the graph returns a shortlist instead of an answer, a single pass gives up. It lost 3 of 100 questions that way.

890

Agents pay on every question

Agentic GraphRAG reaches 100%, but spends ~890 tokens per question, including the 97 that did not need it.

How OCCAM works

Escalate only when a tier can name what it was missing.

Escalation is never a guess about difficulty. Every tier reports its gap, and that gap is recorded in the trace, so the controller cannot silently skip evidence.

Accuracy and completeness

We report answer accuracy and evidence recall separately. RAG's 63% against 76% recall is the whole argument for doing both.
